# The Museum of Unfinished Days

A first-person, single-player narrative mystery prototype targeting **Unity 6.3 LTS** and URP. The reference board is art direction; the current gallery and instrument are runtime-built greybox geometry, not finished art.

## Current prototype

The compact gallery is generated by `Assets/Scripts/GalleryPrototype.cs`. It includes mouse-look/WASD movement, three inspectable artifacts, a contextual interaction prompt, inspection panels, a session evidence journal, pause/resume UI, and a deterministic three-ring astronomical regulator. The regulator is implemented in `ClockworkPuzzle.cs`; `GalleryUI.cs` presents gameplay and story panels, `EvidenceJournal.cs` keeps unique session discoveries, and `MuseumStoryProgression.cs` stores the one-scene dialogue phase and player choice.

### Open and run locally

1. Install Unity **6000.3 LTS** with a desktop build module.
2. Open this repository as a Unity project and allow the manifest's URP 17.3.0 and Unity UI packages to resolve.
3. Assign a URP asset under **Project Settings > Graphics** and **Quality** if the Editor has not already done so (use the URP creation wizard / Render Pipeline Converter).
4. Open `Assets/Scenes/Gallery.unity` and press **Play**. Walk down the gallery to the brass astronomical regulator near the far end.
5. Inspect **Astronomical model** to read the ring clue, then press **J** to review the journal.

### Controls

- **WASD** — move; **mouse** — look.
- **E** — inspect a targeted artifact, or enter the clockwork puzzle when its prompt is visible.
- **J** — open/close the evidence journal. Evidence is unique and session-only; scroll the journal to review a longer list.
- **Escape** — close ordinary inspection, journal, or puzzle panels first; from normal gameplay, open pause; from pause, resume. Escape does not dismiss an active discovery, dialogue, or unanswered choice. After making a choice, Escape can leave the response screen.
- **Puzzle:** **1 / 2 / 3** select outer / middle / inner ring; **A / D** rotate one 45-degree step counterclockwise / clockwise; **R** resets an unsolved puzzle; **Escape** exits it. The chart's solution is 2 / 5 / 1 clockwise steps from the initial marks.
- **Story sequence:** **Enter** or **Space** advances the discovery and each intercom line. At the choice, press **1** to share the record or **2** to keep it private; the visible choice cards can also be clicked. Press **Enter**, **Space**, or **Escape** on the outcome screen to return to the gallery.
- Click **Resume** to continue from pause. **Return to Main Menu** remains disabled because there is no main-menu scene.

The controller uses the legacy Input Manager axes. If changing Active Input Handling to “Input System Package (New)” only, set it to **Both** or migrate the controller first.

## Manual test checklist

### Clockwork and discovery

- [ ] Inspect the astronomical model; confirm its journal clue gives North Star, Crescent, Morning Star outside-in.
- [ ] Approach the display; verify the **E** prompt, puzzle objective, current ring state, selection feedback, and controls.
- [ ] Select rings with **1 / 2 / 3** and rotate with **A / D**. Confirm discrete steps and wrap; an incorrect configuration remains unsolved and reports dark-indicator feedback.
- [ ] Change positions and press **R**; verify all three return to their start marks.
- [ ] Enter outer 2, middle 5, inner 1 clockwise steps. Verify the indicator lights, archive plaque appears, and **The Unregistered Day** discovery panel triggers once.
- [ ] Verify the full fragment appears once in the journal. Reopen the solved puzzle; confirm it does not replay the discovery or duplicate evidence.

### Dialogue and choice

- [ ] From the discovery panel, advance through each exchange with **Enter / Space**. Verify speaker labels and the full exchange with Dr. Elara Voss.
- [ ] Press **Escape** during discovery/dialogue; confirm the scene does not silently discard the sequence or unanswered choice.
- [ ] At the choice, use **1** and verify the shared-record response; restart Play mode, solve the puzzle again, and use **2** to verify the private response. Also verify each visible card works with the mouse.
- [ ] Open the journal after each branch. Confirm it records exactly one `The Unregistered Day` clue and one `Noah's answer to Dr. Voss` entry describing the selected branch and response.
- [ ] Verify the response screen returns to gameplay using its button, **Enter / Space**, or **Escape**. Confirm mouse look and movement resume, and reopening the solved puzzle does not restart the sequence.
- [ ] Recheck artifact inspection, journal toggle, pause/resume, and puzzle close controls.

## Story scope, performance, and verification

Solving the clockwork reveals **ARCHIVE FRAGMENT 07 — THE UNREGISTERED DAY**: the record predates the event it describes, its original author was removed, and a later note connects Noah to a room before its doors opened. A small amber-lit plaque appears beside the regulator. Dr. Elara Voss calls over a text-only intercom. Noah can either share the inscription (Elara warns that archive dates were corrected) or withhold it (she ends the call; Noah resolves to investigate alone). The choice is held in the `MuseumStoryProgression` component for the current scene session and logged in the journal. No consequences in future chapters are implemented or claimed.

The ring meshes and archive plaque use lightweight Unity primitives/procedural geometry. No external assets, packages, or audio are added. There is no main menu, persistent save system, additional chapter, or ending. Unity Editor is not installed in the implementation workspace; package resolution, compilation, scene import, and Play Mode have **not been verified here**. Use the checklist above for local verification.
